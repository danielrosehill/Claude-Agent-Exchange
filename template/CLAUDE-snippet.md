## File exchange (Google Shared Drive)

Files pass between us through a Google Shared Drive (plugin `agent-exchange`). "I just shared it", "it's in fe" or
"check the drive" means skill `fetch-from-drive`. To leave a file for me, use skill `send-to-drive`. With no Drive
configured, use `read-from-human` and `save-for-user`. The rules are in those skills.
